# Resting-State-Preprocessing-GUI

## Requirements
Requires [fNIRS-Preprocessing](https://github.com/Western-SPRINT/fNIRS-Preprocessing)

## Setup
1. Add the top level folder to your MATLAB path
1. Call `GUIRestingStatePreprocessing` to launch the GUI
